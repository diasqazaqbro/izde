# Чат

Чат Izde устроен по той же схеме, что чат в приложении Claude: слева история диалогов, по центру переписка, внизу поле ввода, справа панель, которая открывается по требованию. Отличие в том, что Izde отвечает только по документам университета и каждое утверждение подтверждает цитатой.

Берём схему и удобство, а не внешний вид: цвета, шрифт и компоненты свои, из `02-design.md`.

## Главная идея

Ответу можно верить, потому что источник виден сразу. В тексте ответа стоят номера ссылок, по клику справа открывается документ на нужном пункте. Студент видит и ответ, и место, откуда он взят, не уходя из чата.

## Раскладка

### Десктоп (от 1024 px)

```
+-----------+---------------------------+----------------+
| История   | Переписка                 | Источник       |
| 260 px    | колонка до 760 px         | 420 px         |
|           |                           | (по клику)     |
| + Новый   | вопрос                    | название       |
| Поиск     | шаги: «Ищу в документах»  | пункт          |
| Сегодня   | ответ со ссылками [1][2]  | цитата         |
| Вчера     | действия, подсказки       | открыть        |
| Раньше    |                           | документ       |
|           | [ поле ввода ]            |                |
+-----------+---------------------------+----------------+
```

- Историю можно свернуть кнопкой в шапке чата.
- Панель источника закрыта, пока не нажата ссылка. Когда она открыта, колонка переписки сужается, а не перекрывается.

### Телефон

- История — панель, выезжающая слева по кнопке.
- Источник — панель, выезжающая снизу на 85% высоты.
- Поле ввода прижато к низу и не перекрывается клавиатурой.

## Пустой чат

По центру приветствие в одну строку («Что нужно найти?»), под ним поле ввода и четыре плитки с примерами вопросов (те же, что на главной). После первого сообщения поле уезжает вниз.

## Поле ввода

- Растёт по высоте до 8 строк, дальше прокрутка внутри.
- Enter отправляет, Shift+Enter переносит строку. На телефоне Enter переносит строку, отправка кнопкой.
- Пока идёт ответ, кнопка отправки превращается в «Стоп».
- Слева от кнопки отправки — выбор области: «Все документы» или один документ. Если чат открыт из карточки документа, область уже выбрана.
- Пустое сообщение отправить нельзя.

## Как идёт ответ

1. Сообщение пользователя появляется сразу.
2. Под ним строка шагов: «Ищу в документах…», затем «Нашёл 3 фрагмента в 2 документах». Строку можно раскрыть и увидеть список найденных документов.
3. Ответ печатается по мере поступления.
4. После ответа появляются ссылки-источники, действия и подсказки.

Если ответ остановили кнопкой «Стоп», остаётся то, что успело напечататься, с пометкой «Ответ остановлен».

## Ссылки на источники

- В тексте — маленькие круглые номера `[1]`, `[2]` сразу после утверждения.
- Под ответом — ряд карточек-источников: название документа, пункт.
- Клик по номеру или карточке открывает панель источника: название, код, раздел, пункт, цитата с подсветкой, кнопка «Открыть документ» (ведёт в карточку документа на этот пункт).
- Наведение на номер на десктопе показывает подсказку с цитатой.

## Когда ответа нет

Если в документах нет ответа, Izde так и пишет: «В документах этого нет». Ниже — что можно сделать: переформулировать вопрос или посмотреть ближайшие по теме пункты (если они есть). Ответ без источника не выдаётся никогда.

## Действия под ответом

- Копировать.
- Повторить (сгенерировать ответ заново).
- «Полезно» и «Не то»: отметка уходит в аналитику админки. После «Не то» можно коротко написать, что не так.

## Подсказки

Под последним ответом — до трёх уточняющих вопросов плитками. Клик отправляет вопрос.

## История диалогов

- Кнопка «Новый чат» сверху.
- Поиск по названиям чатов.
- Группы: «Сегодня», «Вчера», «Раньше».
- Название чата создаётся автоматически из первого вопроса, его можно переименовать.
- Чат можно удалить, с подтверждением внутри интерфейса.
- История у каждого пользователя своя.

## Связь с поиском

- В результатах поиска под блоком ответа есть кнопка «Продолжить в чате». Она открывает новый чат, в котором уже лежат вопрос и ответ.
- В карточке документа есть кнопка «Спросить по документу». Она открывает новый чат с областью «этот документ».

## Язык

Izde отвечает на языке вопроса: русском, казахском или английском. Цитаты остаются на языке документа.

## Оформление ответа

Ответ может содержать абзацы, списки, жирный текст и таблицы. Заголовков в ответе нет. Длинные таблицы прокручиваются внутри своего блока.

## Клавиатура

| Сочетание | Действие |
|---|---|
| Cmd/Ctrl + K | новый чат |
| Cmd/Ctrl + / | фокус в поле ввода |
| Esc | закрыть панель источника или остановить ответ |
| ↑ в пустом поле | отредактировать последнее сообщение |

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Идёт поиск | строка шагов с анимацией |
| Идёт ответ | текст печатается, кнопка «Стоп» |
| Ошибка сети | «Не получилось ответить. Проверьте интернет.» и кнопка «Повторить» |
| Лимит сообщений | «На сегодня лимит вопросов закончился. Поиск работает без ограничений.» |
| Нет документов в базе | «В базе пока нет документов» и для админа ссылка на загрузку |

## Ограничения

- Лимит вопросов в день на пользователя (число задаёт тариф), чтобы контролировать расходы на LLM.
- Длина вопроса до 2000 символов.

## Что в фазе 1 (на моках)

Весь интерфейс чата работает: история, поле ввода, печать ответа, шаги, ссылки, панель источника, действия, подсказки, состояния. Ответы берутся из мок-слоя: для вопросов, которые совпадают с пунктами из `05-data.md`, отдаётся подготовленный ответ с настоящей цитатой, для остальных — «В документах этого нет». Печать имитируется задержками. История хранится в браузере.
