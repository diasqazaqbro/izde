# Дизайн

Эталон — `prototype.html` (открой в браузере, войди с любыми данными). Страница поиска в нём утверждена пользователем. Остальные экраны делай в том же стиле.

## Принципы

- **Просто.** На экране одна главная вещь. На главной это поле поиска.
- **Один акцент.** Синий только для действий, ссылок и активных состояний. Остальное — белое, серое, чёрное.
- **Воздух.** Крупные отступы, крупные скругления, мало линий.
- **Ничего декоративного.** Если элемент ничего не сообщает и ничего не делает, его нет.

| `--mark` | `#fff3bf` | подсветка найденного |

| `--wait` | `#8a5a00` | статус «в очереди» |
| `--danger` | `#c62828` | ошибки, удаление |

Радиусы: карточки 18 px, плитки 16 px, поля 12 px, кнопки и поле поиска — полностью круглые (999 px).

Тени: только у поля поиска (`0 12px 32px rgba(0,0,0,.07)`) и у выезжающих панелей. Карточки отделяются границей в 1 px, без тени.

## Компоненты

- **Шапка**: липкая, полупрозрачная с размытием. Слева «Izde» и метка «IITU», справа разделы, язык, профиль.
- **Поле поиска**: круглое, слева лупа, справа круглая синяя кнопка со стрелкой. На главной выше (56 px), на остальных экранах 44 px. Пока поле пустое, на главной в нём по буквам печатаются примеры запросов.
- **Переключатель режима**: сегменты «По смыслу / По словам».
- **Плитка-пример**: серая, со стрелкой справа, при наведении голубая.
- **Блок ответа**: голубой фон, метка «Ответ по документам», текст 18 px, ссылка на источник.
- **Строка результата**: название документа, код и раздел, цитата с подсветкой.
- **Статус**: «таблетка» с точкой: зелёная «Готов», жёлтая «В очереди», красная «Ошибка».
- **Кнопки**: основная (синяя, круглая), вторичная (белая с границей), текстовая.
- **Пустые состояния**: заголовок, одно предложение, одно действие.

## Экраны

- **Вход**: карточка по центру, название, два поля, кнопка.
- **Поиск**: всё по центру: название «Izde.» с синей точкой, строка описания, поле, режим, плитки с примерами, строка со счётчиком документов.
- **Результаты**: поле сверху, блок ответа, счётчик, список. Фильтры — ряд выпадающих списков под полем, на телефоне в выезжающей снизу панели.
- **Карточка документа**: назад, название, мета, найденные пункты (активный подсвечен), оглавление.
- **Чат**: см. `03-chat.md`.
- **Админка**: слева или сверху вкладки «Сводка / Документы / Аналитика / Пользователи». Таблицы на телефоне превращаются в карточки.
- **Тарифы**: три колонки, текущий план отмечен, на телефоне в столбик.

## Доступность

- Контраст текста от 4.5:1.
- Кликабельные зоны от 44 px на телефоне, от 28 px на десктопе.
- Фокус с клавиатуры виден: обводка 3 px цветом `--accent`.
- Состояние передаётся не только цветом: у статуса есть текст.
- Анимации отключаются при `prefers-reduced-motion`.

## Чего не делать

Градиенты, эмодзи вместо иконок, тени у каждой карточки, несколько акцентных цветов, тёмная тема (на этой фазе), центрирование всего подряд на внутренних экранах.
