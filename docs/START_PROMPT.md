# Стартовый промпт для Claude Code

Запускать из папки `izde/`.

```
Ты начинаешь проект Izde: поисковик по документам университета. Сейчас в папке есть только документация, кода нет.

Сначала прочитай целиком CLAUDE.md и все файлы в docs/ по порядку номеров. Открой docs/prototype.html и изучи разметку и стили: это утверждённый прототип, страница поиска должна выглядеть так же.

Задача этой сессии — шаг 1 из docs/06-roadmap.md: основа проекта и поиск. Чат, админку и тарифы пока не делай, но заложи структуру так, чтобы они легли без переделок.

Что должно получиться:
1. Проект Next.js 16+ в frontend/ (App Router, React 19, TypeScript strict, Tailwind CSS v4). Перед тем как писать код, сверь с документацией установленной версии то, что в Next.js 16 поменялось: кеширование, асинхронные params и searchParams, файл для перехвата запросов. Не полагайся на память.
2. Токены и базовые компоненты из docs/02-design.md.
3. Слой данных src/lib/api по docs/04-architecture.md: типы, интерфейс, мок-реализация. Данные только из docs/05-data.md, логику совпадений перенеси из массива CLAUSES в прототипе.
4. Словарь ru и переключатель языка RU/KZ/EN (kk и en пока с откатом на ru).
5. Вход (мок), защита маршрутов, шапка.
6. Главная с поиском, результаты (?q=&mode=), карточка документа.

Правила:
- Не придумывай документы, пункты и цитаты. Если чего-то не хватает, спроси меня.
- Каждый экран проверь на ширине 390 px и 1280 px.
- Работай в ветке dev, коммить небольшими шагами. Ничего не пушь.
- Если есть вопросы, которые меняют решение, задай их до начала, не больше трёх. Менеджер пакетов спроси один раз.

Порядок работы: сначала покажи короткий план и дождись моего «ок». Потом делай. В конце запусти проверку типов, линтер и сборку, заполни раздел «Команды» в CLAUDE.md и напиши отчёт: что сделано, что не сделано, что проверено и как запустить.
```
