# Прогресс

Рабочий журнал фазы 1. Обновляется после каждого коммита. Если контекст потерян, продолжать отсюда.

## Сделано

- Шаг 1: основа, токены, слой данных, i18n (ru), вход, поиск, результаты, карточка документа. Принят пользователем.
- Шаг 2: чат по `docs/03-chat.md`. Проверен в Chrome: отправка по Enter, Shift+Enter, рост поля до 8 строк, шаги поиска, печать, «Стоп» с пометкой, номера ссылок с подсказкой, панель источника (справа и снизу), переход в карточку на пункт, «В документах этого нет», копировать, повторить, «Полезно / Не то» с комментарием, подсказки, история (поиск, переименование, удаление с подтверждением, сохранение после перезагрузки), «Продолжить в чате», «Спросить по документу» с областью, Cmd+K, Cmd+/, Esc, ↑, ошибка сети, лимит, телефонная раскладка.

- Шаг 3: админка (сводка, документы с загрузкой, аналитика, пользователи) и тарифы с заглушкой оплаты. Проверено в Chrome: студента не пускает, админа пускает, загрузка PDF показывает «отключено в демо», PNG отклоняется, оплата меняет тариф, смена роли сохраняется, демо-данные помечены. Аудит 390/1280 чистый, таблицы на телефоне — карточки.

## Как проверять

- Из `frontend/`: `npm run typecheck && npm run lint && npm test && npm run build`.
- Chrome MCP: окно развёрнуто на весь экран, `resize_window` не уменьшает его (ширина остаётся 1512). Узкие экраны проверяются во фрейме: открыть любую страницу сайта и подменить `body` на `<iframe src="/chat" style="width:390px;height:670px">`.
- Аудит экранов: `scratchpad/audit.mjs` (Playwright с установленным Chrome). Проверяет горизонтальную прокрутку, зоны клика от 44 px на 390, наличие h1, контраст, ошибки консоли. Запуск: `node audit.mjs student|admin /путь …`.
