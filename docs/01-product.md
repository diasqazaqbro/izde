# Продукт

## Проблема

В университете около 1000 документов (наша оценка): положения, правила, приказы. Обычный поиск находит документ, только если ввести точное слово из него. Студент пишет «можно ли пересдать экзамен» и не находит пункт про оценку FX, потому что документ написан другими словами или на другом языке.

## Для кого

- **Студент**: ищет правило, читает пункт, задаёт вопрос в чате.
- **Сотрудник** (преподаватель, деканат): то же, что студент.
- **Администратор вуза**: загружает документы, следит за индексацией, смотрит, что ищут, управляет доступом и тарифом.

## Что умеет

1. Поиск по словам: находит документ, когда известен точный термин.
2. Поиск по смыслу: находит пункт по вопросу своими словами. (ML)
3. Ответ над результатами: короткий ответ с источником, кнопка «Продолжить в чате». (AI-агент)
4. Чат: диалог по документам с цитатами и историей. Подробно в `03-chat.md`. (AI-агент)
5. Поиск на русском, казахском и английском: язык запроса не обязан совпадать с языком документа. (ML)
6. Фильтры: тип документа, год, подразделение.
7. Карточка документа: найденный пункт подсвечен, есть оглавление и ссылка на исходный файл.
8. Загрузка документов администратором: PDF и DOCX, статус индексации.
9. Тарифы и оплата: лимит по числу документов, оплата через заглушку. (Оплата)

## Экраны

| Экран | Кто видит | Что на нём |
|---|---|---|
| Вход | все | почта, пароль. Без входа сайт недоступен |
| Поиск (главная) | все | название, поле поиска, режим «по смыслу / по словам», примеры запросов |
| Результаты | все | ответ с источником, список фрагментов, фильтры |
| Карточка документа | все | найденные пункты, оглавление, ссылка на файл, кнопка «Спросить по документу» |
| Чат | все | история диалогов, сообщения, панель источника |
| Админка: сводка | админ | документов в базе, заполненность тарифа, ошибки индексации, запросы за неделю |
| Админка: документы | админ | список со статусами, загрузка файлов |
| Админка: аналитика | админ | частые запросы, запросы без результата |
| Админка: пользователи | админ | список, роли. Необязательный блок, делается последним |
| Тарифы и оплата | админ | три плана, заглушка оплаты |

## Тарифы

| План | Лимит документов | Цена |
|---|---|---|
| Free | до 100 | бесплатно |
| Standard | до 1 000 | условная, с пометкой «пример» |
| Campus | до 10 000 | условная, с пометкой «пример» |

Оплата — заглушка: форма, имитация платежа, смена плана. Настоящего провайдера нет.

## Принятые решения

- Интерфейс на русском, переключатель RU / KZ / EN в шапке.
- Светлая тема в духе Apple, один акцент (синий).
- Всё адаптивное, включая админку.
- Весь сайт только после входа.
- Мок-данные только из реальных документов IITU (`05-data.md`).
- В шапке название вуза текстом «IITU», без логотипа и фирменных цветов университета.

## Чего не делаем

- Граф связей между документами (это часть диплома, не этого проекта).
- Редактирование документов.
- Настоящие платежи.
- Мобильное приложение.

## Открытые вопросы

- Откуда берём полный корпус документов. Запасной план: открытые документы с сайтов вузов и adilet.zan.kz.
- Как устроен настоящий вход: почта и пароль или вход через аккаунт вуза.
- Ждёт ли преподаватель настоящую платёжную интеграцию вместо заглушки.
