# Izde: инструкции для Claude Code

Izde — поисковик по документам университета: поиск по словам, поиск по смыслу и чат, который отвечает со ссылкой на источник. Учебный командный проект (IITU, курс Web Programming), тимлид — Dias.

## Что читать перед работой

1. `docs/01-product.md` — что и для кого делаем
2. `docs/02-design.md` — дизайн-система и экраны
3. `docs/03-chat.md` — чат
4. `docs/04-architecture.md` — структура, маршруты, типы, контракт API
5. `docs/05-data.md` — мок-данные (только реальные документы IITU)
6. `docs/06-roadmap.md` — фазы и задачи
7. `docs/prototype.html` — утверждённый прототип. Это эталон внешнего вида страницы поиска.

## Текущая фаза

Фаза 1: фронтенд на мок-данных в папке `frontend/`. Бэкенда и ML пока нет. Все данные идут через слой `frontend/src/lib/api`, чтобы позже заменить моки на HTTP-запросы без переписывания экранов.

## Стек фронтенда

- Next.js 16 или новее, App Router, React 19, TypeScript в режиме strict
- Tailwind CSS v4, токены из `docs/02-design.md`
- Свои компоненты. Для диалогов, выпадающих меню и выезжающих панелей можно взять Radix UI. Тяжёлые UI-киты не подключать.
- Иконки: lucide-react
- Состояние: состояние React и параметры URL. Стор подключать, только если без него не обойтись.

## Правила

- **Версии.** API Next.js 16 сверяй с документацией установленной версии, а не с памятью: в 16-й версии менялись кеширование, асинхронные `params` и файл для перехвата запросов. Если не уверен, открой документацию.
- **Данные.** Названия документов и цитаты бери только из `docs/05-data.md`. Не придумывай документы, пункты и цитаты. Числа, которых в реальности ещё нет (статистика запросов, пользователи), показывай с пометкой «демо-данные».
- **Тексты.** Интерфейс на русском, все строки лежат в словаре (`ru`, `kk`, `en`), а не в компонентах. Пиши коротко и по делу: кнопка называет действие, ошибка говорит, что случилось и что сделать.
- **Адаптив.** Каждый экран работает на ширине 390 px и 1280 px, без горизонтальной прокрутки.
- **Доступность.** Контраст текста от 4.5:1. Кликабельные зоны от 44 px на телефоне и от 28 px на десктопе. Видимый фокус с клавиатуры. Уважай `prefers-reduced-motion`.
- **Дизайн.** Светлая тема, один акцентный цвет (синий). Без градиентов, без эмодзи вместо иконок, без тёмной темы на этой фазе.
- **Git.** Работай в ветке `dev`, коммиты небольшие и по одной теме. Не пушь и не создавай репозиторий на GitHub без просьбы пользователя.
- **Секреты.** Ключей и токенов в репозитории быть не должно. На фазе 1 они не нужны.

## Готово — это когда

- проходят проверка типов, линтер и сборка
- экран проверен на 390 px и 1280 px
- нет выдуманных документов и цитат
- в отчёте сказано, что сделано, что не сделано и что проверено

## Команды

Менеджер пакетов — npm, Node 20.9+. Все команды из папки `frontend/`:

- `npm install` — установка
- `npm run dev` — запуск для разработки, http://localhost:3000
- `npm run typecheck` — проверка типов (сначала генерирует типы маршрутов)
- `npm run lint` — линтер
- `npm test` — тесты (vitest)
- `npm run build` и `npm start` — сборка и запуск собранной версии

Документация установленной версии Next.js лежит в `frontend/node_modules/next/dist/docs/`.
